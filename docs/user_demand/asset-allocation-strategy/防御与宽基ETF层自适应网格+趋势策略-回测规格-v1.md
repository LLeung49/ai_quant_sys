# 防御与宽基 ETF 层自适应网格＋趋势策略——回测规格 v1

## 1. 文档目的

本文将《防御与宽基etf层自适应网格+趋势策略.md》的策略理念固化为可复现、可做滚动样本外验证、可与每日影子运行共用的交易规格。

本阶段只研究防御型与境内宽基权益 ETF 中适合运行本策略的标的，并锚定稳定参数区间。已经规划为长期核心配置的国债/固收、纳指 100 ETF、标普 500 ETF 不进入本阶段标的筛选。顶层资产比例不在本阶段重新优化。

本策略只做多，不做空，不使用融资或杠杆。全部信号在交易日收盘后产生，最早于下一交易日执行。

## 2. 研究目标

回测需要回答四个问题：

1. 哪些防御型或境内宽基指数/风格最适合本策略。
2. 同一指数/风格下，哪只具体 ETF 的历史长度、流动性、成本后收益和执行稳定性更好。
3. GRID、TREND 及完整状态机分别贡献了多少收益和风险。
4. 哪些参数属于跨标的、跨窗口有效的稳定区域，可冻结后用于每日运行。

## 3. 时间与成交口径

### 3.1 信号时点

- T 日收盘后，只使用截至 T 日已经可得的数据计算指标、状态、风险线和订单。
- T 日信号不得在 T 日成交，订单最早在 T+1 执行。
- 趋势入场、加仓、退出、止损，以及网格初始化、买入、卖出均遵守同一时点规则。
- 周五收盘没有产生信号、周一开盘才出现跳空时，不在周一开盘临时生成订单；最早由周一收盘确认并于周二执行。

### 3.2 日频撮合

- 市价型调仓以 T+1 可成交价格模拟，基准实现采用开盘价并叠加滑点。
- 不使用日内最高价和最低价推测同一天网格买卖的先后顺序。
- 停牌、涨跌停、流动性不足或其它不可成交情形必须产生未成交或延迟成交结果，不能假设按信号价成交。
- 只有订单实际成交后，才更新持仓、单位数、网格锚点和相关状态。
- 每笔订单保存信号日、计划执行日、实际成交日、成交价格、未成交原因、策略状态、参数版本和触发原因。

### 3.3 价格与权益口径

- 复权 OHLC 用于收益与 ADX、ATR、MACD、布林带、唐奇安通道等信号计算。
- 真实未复权价格用于成交、100 份取整、佣金和滑点计算。
- 所有价格比较必须位于同一坐标系：`grid_anchor`、`cycle_entry_price`、GRID/TREND 止损线和加仓线均保存信号价格坐标值；实际成交价通过成交日复权因子转换后写入这些字段，真实成交成本另存于持仓账本。
- 发生分红或份额折算时，持久化的信号价格字段按当日复权因子变动同步重标，保证除权前后的锚点和止损含义不变。ATR 风险距离在生成真实订单份额前转换回成交价格坐标。
- 分红、份额折算等权益事件单独调整现金和持仓数量。
- 成交额和流动性使用真实历史成交额。
- 买入持有基准使用包含现金分红的总回报口径。
- 数据源无法可靠提供复权因子或权益事件时，ETF 必须标记数据质量等级，不得静默使用复权价格代替真实成交价格。

## 4. ETF 历史标的池

### 4.1 纳入范围

- 境内上市的普通权益类 ETF。
- 防御风格包括红利、红利低波、低波、价值、质量、高股息等。
- 宽基包括核心宽基、中小盘宽基、成长宽基及其它境内全市场或规模指数。

### 4.2 排除范围

- 债券、货币、黄金、白银及其它商品 ETF。
- 跨境、QDII、纳指 100、标普 500 等海外市场 ETF。
- 杠杆、反向或其它非普通多头权益产品。

### 4.3 历史时点准入

每个信号日动态检查：

- 已上市至少 252 个交易日。
- 过去 20 日平均成交额不低于 1000 万元。
- 当日存在完整有效的行情和成交额数据。
- 当日处于正常交易状态。

只有满足准入条件的 ETF 才能首次初始化 GRID 或进入 TREND。已持仓 ETF 的 20 日平均成交额跌破 1000 万元后，禁止网格买入、趋势入场和趋势加仓，但仍允许风险降低型卖出。报告对 3000 万元和 5000 万元流动性门槛做敏感性分析。

历史池必须包含当时已上市、后来清盘或退市的 ETF，不能只使用当前存续名单。清盘、退市和最后可交易日按历史实际数据处理。

## 5. 市场状态机

状态只有 `GRID` 和 `TREND`，ADX 只判断趋势强度，不判断方向：

```text
ADX > 25       -> TREND
ADX < 20       -> GRID
20 <= ADX <=25 -> 保持上一状态
```

- ADX 采用 14 日周期。
- 首次启动且 ADX 位于 20～25 时，不产生新交易，直到首次明确突破 25 或跌破 20。
- Hurst 指数在 v1 中仅作为研究特征写入报告，不参与状态判断或参数筛选。
- 风险止损、趋势退出、状态切换和加仓/买入的优先级依次为：止损、趋势退出、ADX 状态切换、买入或加仓。

## 6. GRID 模式

### 6.1 布林通道与等比步长

```text
中轨 = MA20
上轨 = MA20 + 2 * STD20
下轨 = MA20 - 2 * STD20
```

布林通道负责动态适应价格和波动，网格步长 `grid_step` 在一个验证窗口和一个实盘冻结周期内保持不变。

候选步长：

```text
grid_step = 1.0%～6.0%，间隔 0.5%
```

### 6.2 GRID 初始化仓位

首次进入 GRID 或一轮趋势交易结束后重新进入 GRID 时，T 日收盘确认，T+1 建立初始化仓位。订单实际成交价转换到信号价格坐标后，成为新一轮 `grid_anchor` 和 `cycle_entry_price`；真实成交价保留在持仓成本账本中。

并行验证三类初始化模型：

1. 固定仓位：30%、40%、50%、60%、70%。
2. 布林位置动态仓位：

```text
position_in_band = clip((close - MA20) / (2 * STD20), -1, 1)
initial_position = 50% - 20% * position_in_band
```

3. 252 日价格分位动态仓位：

```text
0%～20%分位   -> 70%
20%～40%分位  -> 60%
40%～60%分位  -> 50%
60%～80%分位  -> 40%
80%～100%分位 -> 30%
```

动态模型只有在多数样本外窗口和多个 ETF 上稳定优于固定 50% 基准时，才允许进入最终策略。

### 6.3 网格锚点与触发

布林带控制有效风险区间，最近一次实际成交价控制网格触发：

```text
买入触发：close_T <= grid_anchor * (1 - grid_step)
卖出触发：close_T >= grid_anchor * (1 + grid_step)
```

- 订单在 T+1 执行，实际成交后用成交价更新 `grid_anchor`。
- 未成交、停牌或涨跌停时不更新锚点。
- 布林带每日更新，但不得回写已有持仓成本、已实现收益或历史成交。
- 收盘价跌破布林下轨时禁止继续网格买入。
- 卖出属于降低风险的动作，只要达到网格卖出条件并有可用持仓，即使价格位于通道外也允许执行。
- ADX 状态切换优先于网格订单。

### 6.4 单格仓位与 Gap 控制

```text
grid_unit_pct = 单次网格交易金额 / 该ETF策略预算
```

候选参数：5%、10%、15%、20%。

- 每下跌一格，目标仓位最多增加一个 `grid_unit_pct`。
- 每上涨一格，目标仓位最多减少一个 `grid_unit_pct`。
- `max_grid_per_day = 1`，即收盘一次跨越多档也只生成一档订单。
- 总仓位不得低于 0% 或超过 100%。
- 买入份额按实际成交价格向下取整到 100 份；不足一手时不交易。
- `grid_unit_pct` 在一轮 GRID 周期内固定，不因剩余现金或布林带宽度自动放大。

### 6.5 GRID 风险线

GRID 使用只能上移的 3 ATR 吊灯止损：

```text
new_stop = highest_close_since_grid_entry - 3 * ATR20
grid_stop_price = max(previous_grid_stop_price, new_stop)
```

首次建仓时，以首次实际成交价初始化周期高点和风险线。后续补仓可以降低 `grid_anchor` 和平均成本，但不能降低 `grid_stop_price`。

价格按 T 日收盘确认跌破有效止损，T+1 清仓。清仓后至少冷却 5 个交易日，并同时满足收盘重新站上 MA20、ADX < 20，才允许重新初始化 GRID。

## 7. TREND 模式

### 7.1 首次入场

完整趋势入场条件为：

```text
ADX > 25
且 close_T > 前20个交易日最高价（不包含T日）
且 MACD DIF_T > DEA_T
且成交额放大条件通过
```

成交额条件：

```text
amount_ratio = amount_T / 前20日平均成交额
候选阈值 = 1.0、1.2、1.5
```

趋势模块并行运行消融对照：

1. ADX＋20 日突破。
2. ADX＋20 日突破＋`DIF > DEA`。
3. ADX＋20 日突破＋`DIF > DEA`＋成交额放大。

不要求入场当天刚好发生 MACD 金叉。成交额过滤只有在样本外稳定优于简化模型时才保留。

### 7.2 ATR 风险单位

每个买入单位使用信号日可得的 ATR20：

```text
N_i = ATR20 on signal date
stop_distance_i = stop_n * N_i
unit_shares_i = floor_to_100(
    ETF策略预算 * risk_per_unit / stop_distance_i
)
```

固定 `stop_n = 2.0`。候选参数：

```text
risk_per_unit = 0.25%、0.50%、0.75%、1.00%
```

- 不强制最少买入 100 份；计算结果不足一手时放弃信号。
- 单 ETF 总持仓不得超过其策略预算。
- 每次买入前检查现金、仓位上限及全部持仓在当前止损线下的总风险。总计划止损风险不得超过 `ETF策略预算 * risk_per_unit * max_units`。
- T+1 出现不利跳空时，按实际可成交价格重新检查份额和止损风险；必要时缩减至满足风险上限的整手数量，不足一手或开盘已跌破止损线时取消入场/加仓。

### 7.3 金字塔加仓

候选参数：

```text
add_n = 0.5、0.75、1.0
max_units = 2、3、4
```

下一加仓触发价：

```text
最近一次实际买入成交价 + add_n * 最近单位的N_i
```

- T 日收盘确认，T+1 买入。
- 单日最多增加一个单位，跳空跨越多档也不追买多档。
- 每次加仓按当次信号日 ATR 和剩余风险预算重新计算份额。
- MACD 和成交额只控制首次入场；已有趋势仓加仓只要求仍为 TREND、达到加仓线、无退出信号且风险检查通过。
- 实际成交后才推进最近加仓价和单位数。

### 7.4 趋势止损与退出

趋势止损只能上移：

```text
candidate_stop = 最新买入成交价 - stop_n * 当次信号日ATR
trend_stop_price = max(previous_trend_stop_price, candidate_stop)
```

以下任一条件在 T 日收盘成立，T+1 清空全部趋势仓：

```text
close_T < trend_stop_price
或 close_T < 前10个交易日最低价（不包含T日）
或 DIF_T < DEA_T 且 DIF_(T-1) >= DEA_(T-1)
```

## 8. GRID 与 TREND 切换

### 8.1 GRID 转 TREND

ADX > 25 时立即停止生成网格订单并取消尚未成交的网格信号。

若同日满足完整趋势做多条件：

- 原网格持仓不先卖出再买回。
- 按当日 ATR 和趋势风险公式计算第一趋势单位目标份额。
- 网格持仓不足时 T+1 补足；超出风险允许份额时 T+1 减至允许规模。
- 转换后整体仓位记作第一个趋势单位。
- 初始趋势止损取原 `grid_stop_price` 与 `close_T - 2 * ATR20_T` 中较高者。

若不满足完整趋势做多条件：

- T+1 清空网格仓位。
- TREND 状态下保持现金，等待新的完整趋势入场信号。

### 8.2 TREND 转 GRID

ADX < 20 本身不直接清仓。持有趋势仓时：

- 停止趋势加仓。
- 不启动网格订单。
- 标记 `pending_grid = true`。
- 继续由趋势止损、10 日唐奇安退出或 MACD 死叉结束趋势交易。

趋势清仓实际成交后，如果最新收盘仍满足 ADX < 20，则按 GRID 初始化流程建立新周期；如果 ADX 已高于 25，则保持现金并等待新的趋势入场。

TREND 本来为空仓且 ADX 跌破 20 时，可直接按 GRID 初始化流程生成下一交易日订单。

## 9. 灾难止损与风险锁

每轮 GRID 或 TREND 首次实际建仓时设置：

```text
cycle_entry_price = 本轮首次实际成交价转换后的信号价格
hard_stop_price = cycle_entry_price * (1 - 10%)
```

有效止损：

```text
GRID  = max(grid_stop_price, hard_stop_price)
TREND = max(trend_stop_price, hard_stop_price)
```

- 后续网格补仓和趋势加仓不得降低 `hard_stop_price`。
- GRID 转 TREND 且保留原仓位时属于同一个持仓周期，沿用原 `cycle_entry_price`。
- 清仓后建立全新 GRID 或 TREND 周期时才重置 `cycle_entry_price`。
- 触发硬止损后，GRID 按 5 日冷却＋站上 MA20＋ADX < 20 的规则恢复；TREND 必须等待新的完整 20 日突破入场信号。
- 跳空时按实际可成交价计入损失，不能假设在止损线上成交。

## 10. 交易成本

账户实际佣金：

```text
单边佣金 = max(成交金额 * 0.0001, 5元)
```

滑点情景：

```text
基准：单边3 bp
压力测试：单边0、1、5、10 bp
```

- 0 bp 仅表示理论上限，不用于选择生产参数。
- 最终候选至少需要在单边 5 bp 情景下保持样本外有效。
- 税费及其它费用按标的类别和历史交易日期的适用规则建模。
- 报告输出毛收益、佣金、滑点、净收益、平均单格毛利/成本比、最低佣金触发比例及成本情景衰减。

## 11. 参数研究方法

### 11.1 固定安全参数

以下参数不参与收益最大化：

```text
ADX阈值 = 20/25
布林带 = MA20 +/- 2 * STD20
趋势止损 = 2 ATR
网格止损 = 3 ATR
灾难止损 = 10%
单日最大网格档数 = 1
单日最大趋势加仓单位 = 1
GRID止损冷却期 = 5个交易日
```

### 11.2 分阶段筛选

1. GRID 阶段筛选初始化仓位模型、`grid_step`、`grid_unit_pct`。
2. TREND 阶段筛选入场消融模型、`volume_ratio`、`risk_per_unit`、`add_n`、`max_units`。
3. 每个训练窗口只组合 GRID 和 TREND 的稳定候选，再运行完整状态机。
4. 验证窗口完全冻结参数，不继续优化。
5. 优先选择跨 ETF、跨窗口有效的参数簇中间值；孤立尖峰参数不得作为生产参数。
6. 参数优先在指数/风格组层面共享，单 ETF 只有证据充分时才允许偏离。

所有尝试过的参数组合及失败结果必须保留，报告参数邻域敏感性和多重尝试数量。

## 12. 样本外验证

```text
指标预热 = 252个交易日
训练窗口 = 504个交易日
样本外验证窗口 = 126个交易日
滚动步长 = 126个交易日
```

- 参数只能使用训练窗口选择，并冻结到随后半年验证窗口。
- 最终将各段样本外净值拼接作为主要评价结果。
- 历史不足三年的 ETF 可回测，但标记为观察候选，不与长历史标的采用相同置信等级。
- 同时报告全历史、滚动样本外、最近一个完整年度及不同牛熊震荡阶段的表现。

### 12.1 正式验证的账务边界与产物

- 指标可使用验证窗口之前的历史数据预热，但预热期不得产生订单、成交、现金/持仓变化或净值记录。
- 收盘信号最早只能在下一交易日成交；策略与 B&H 均使用同一成本模型和独立的验证期初始资金。
- 正式范围采用 `504/126/126`；历史不足的产品可用 `252/126/126` 作 `reference_only` 参考，但不得进入可激活候选。
- 对每个固定代表性标的发布原子化的 JSON、窗口 CSV、成交 CSV、归因 JSON、Markdown 和价格/指标/买卖点/NAV 三联图。图表和归因只能消费已记录的回测事件，不得重新推导交易。
- 正式激活门槛：年化超额收益大于零、策略最大回撤相对 B&H 的恶化不超过 2 个百分点、且不落后窗口超过半数；数据、日历、价格口径或执行可用性无法证明时一律 `data_rejected`。
- 每日人工操作单属于验证通过后的独立阶段；未通过或 `reference_only` 的标的不得生成真实资金操作建议。

最大回撤先做风险分层，不作为回测前硬淘汰条件：

| 层级 | 优选区 | 可接受观察区 | 高风险区 |
| --- | ---: | ---: | ---: |
| 防御层 | 不高于 15% | 15%～20% | 高于 20% |
| 宽基 ETF 层 | 不高于 20% | 20%～25% | 高于 25% |

组合层最大回撤在候选及相关性结果产生后再确定。

## 13. 对照策略与评估指标

每只 ETF 同时运行：

1. 买入并持有。
2. 固定 50% 仓位持有。
3. 纯网格策略。
4. 纯趋势策略。
5. 完整 GRID/TREND 自适应策略。

不使用单一任意加权总分，采用收益、风险、稳定性和执行性的 Pareto 筛选。

报告至少包括：

- 收益：累计收益、成本后年化收益、相对买入持有收益。
- 风险：最大回撤、回撤恢复时间、年化波动率、Sortino、Calmar、最差半年、CVaR。
- 稳定性：样本外正收益窗口比例、最差窗口、参数邻域稳定性、不同市场阶段表现。
- 交易质量：胜率、盈亏比、利润因子、换手率、平均持有期、最低佣金触发率。
- 成本敏感性：1/3/5/10 bp 滑点下的净收益衰减。
- 策略归因：GRID、TREND、状态切换分别产生的收益、损失和回撤。
- 实盘可行性：未成交率、停牌/涨跌停影响、订单占成交额比例和数据质量。

## 14. 两级选标与组合验证

### 14.1 指数/风格层

先按跟踪指数和风格暴露分组，判断策略最适合的指数或风格，避免同一指数的多个产品重复占据排行榜。

### 14.2 ETF 产品层

同一跟踪指数内比较历史长度、数据完整度、成交额、成本后表现、滑点敏感性，以及数据允许时的跟踪误差、折溢价、基金规模和清盘风险。同一指数最终只保留一只执行质量最好的 ETF。

### 14.3 组合层

- 每个资产层输出完整候选榜，并重点验证由 2～4 只 ETF 组成的组合。
- 优先使用不同指数或风格暴露。
- 评估过去 252 日收益相关性、下跌阶段相关性和回撤重叠。
- 单只 ETF 原则上不超过所属层预算的 50%。
- 并行比较等权分配与带单标的上下限的波动率倒数分配。
- 防御层和宽基层总预算沿用顶层资产配置，不在本研究中重新优化。

最终结果同时给出最佳单标的、Pareto 候选集合、适合实际持有的组合、参数稳定区间和当前日报目标代码。

## 15. 更新与上线节奏

### 15.1 生产更新

- 每日：计算状态、信号、目标仓位、风险线和下一交易日订单，不重新优化参数。
- 每日准入：检查停牌、数据缺失和流动性，失效时禁止增加风险。
- 每月：检查参数失效、实际成本、滑点和数据质量，只预警，不自动换标。
- 每半年：重新执行滚动样本外研究，更新候选、目标 ETF 和参数稳定区间。
- 新参数只在旧交易周期结束后生效，不得中途重写已有锚点、风险线或单位信息。
- 清盘预警、长期停牌、数据失真或流动性严重恶化允许触发紧急处置。

### 15.2 影子与实盘阶段

1. 历史回测通过后，冻结目标、参数、模型版本和配置哈希。
2. 连续运行至少 60 个交易日影子系统，不发送真实订单。
3. 影子阶段通过后进入小资金、人工确认实盘。
4. 真实滑点、佣金和未成交率与模型一致后，自动下单作为独立模块另行设计和授权。

影子阶段最低通过条件：

- 不使用未来数据，不发生信号日与执行日错位。
- 同一数据与配置的信号可复现率为 100%。
- 连续运行无状态、锚点、止损线或持仓账本丢失。
- 模拟实际滑点不显著差于单边 5 bp 压力情景。
- 每笔计划订单都能追溯到冻结参数和明确规则。

## 16. 建议的软件边界

实现时至少拆分以下职责，避免研究、状态和下单逻辑相互污染：

- `UniverseProvider`：按历史时点提供 ETF 池、分类、上市状态和流动性资格。
- `MarketDataProvider`：提供复权信号行情、真实成交行情、权益事件和交易日历。
- `IndicatorEngine`：计算 ADX、MACD、ATR、布林带、唐奇安和研究用 Hurst。
- `RegimeMachine`：只负责 GRID/TREND 状态及滞回。
- `GridEngine`：管理初始化模型、锚点、单格目标和 GRID 风险线。
- `TrendEngine`：管理突破入场、ATR 单位、加仓、趋势止损和退出。
- `RiskEngine`：统一执行灾难止损、预算、流动性、订单优先级和冷却锁。
- `ExecutionSimulator`：处理 T+1、整手、佣金、滑点、停牌、涨跌停和未成交。
- `PortfolioEngine`：执行层内组合、相关性和资金分配。
- `WalkForwardEvaluator`：执行分阶段调参、滚动样本外、对照策略和 Pareto 报告。
- `DailyShadowRunner`：加载冻结配置和持久状态，生成可追溯的次日订单建议，绝不直接下单。

每日持久状态至少包括：市场状态、`pending_grid`、风险锁、冷却计数、`grid_anchor`、周期首次成交价、GRID/TREND 风险线、周期最高收盘、趋势单位明细、下一加仓价、持仓、现金、未成交订单、模型版本和配置哈希。

## 17. 测试与验收原则

实现阶段必须覆盖：

- 每条信号只使用 T 日及以前数据，成交不早于 T+1。
- ADX 20/25 滞回不会在阈值附近来回切换。
- 网格锚点只在真实成交后更新。
- 跳空跨多档时单日最多一档。
- 下轨外禁止买入但允许风险降低型卖出。
- GRID/TREND 止损和 10% 硬止损永不下移。
- GRID 转 TREND 的持仓风险校准正确，无先卖后买的虚假换手。
- TREND 转 GRID 必须先完成趋势退出。
- 不足一手、预算不足、风险超限时拒绝订单。
- 最低 5 元佣金、100 份取整和各滑点场景准确。
- 停牌、涨跌停、数据缺失和权益事件不会产生虚假成交或收益。
- 训练窗口选择的参数在验证窗口严格冻结。
- 同一输入、配置和状态能够生成完全一致的结果。
