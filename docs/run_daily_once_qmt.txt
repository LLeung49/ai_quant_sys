# QMT 日常运行指引

日线唯一维护入口：

    python src/data_ingestion_qmt/8-原始行情与复权数据采集_qmt_bridge.py

存量 QFQ 换手率只从 QMT ContextInfo 回填。先执行只读预演：

    python src/data_ingestion_qmt/10-QFQ换手率全量回填_qmt.py --dry-run --limit-codes 20

确认输出后可执行可恢复回填；脚本只更新 `turnover_rate IS NULL` 的行：

    python src/data_ingestion_qmt/10-QFQ换手率全量回填_qmt.py --batch-size 5

QMT 未返回、无效或请求失败的日期会保留 NULL，不使用当前流通股本或 AkShare 推算。
