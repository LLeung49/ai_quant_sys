# 板块轮动工作台信息层级优化设计

日期：2026-08-12

## 目标

优化板块轮动工作台的信息层级和交互可读性：市场总览只承载市场级指标，行业 Lifecycle 观察与筛选回归象限工作台；日期选择使用按需展开月历；修复排行榜和详情抽屉的可读性。

## 信息层级

### 市场总览

市场总览仅展示市场级指标。当前保留“市场环境”卡片，并预留统一卡片容器供后续添加市场宽度、成交活跃度、波动/风险、风格等市场指标。它不再包含行业 Lifecycle 计数或任何行业筛选按钮。

### 象限工作台

象限图标题区保留“单日观察 / 动态回放”模式切换，并新增“观察重点”分段标签：

- 全部行业；
- 趋势运行；
- 修复/初启；
- 风险提示（拥挤、背离、退出）；
- 今日 Lifecycle 变化。

标签只过滤象限图和“今日关注”排行榜，选中状态明确可见。选择“今日 Lifecycle 变化”时只显示 `lifecycle_changed=true` 的行业；无 Lifecycle 数据的历史快照保持禁用及说明，不伪造筛选结果。

## 日期选择

筛选区仅显示紧凑的日期触发按钮，内容为当前用户选择的交易日和状态提示。用户点击按钮后，月历以绝对定位的弹层展开，不改变筛选区高度。

月历继续保留三态：已生成快照、交易日待生成、非交易日。点击待生成交易日保留选择、关闭弹层、显示已有的回退快照业务提示；点击非交易日无效。点击页面其他区域、按 Escape 或再次点击触发按钮关闭弹层。弹层具备 `aria-expanded` 和适当焦点行为。

## Lifecycle 表达

排行榜的 Lifecycle 仅使用结构化短标签：`状态｜第 N 日｜今日切换`。当没有状态变更时不显示“今日切换”；缺少数据时显示“数据不足”。不再使用可能被误解为“强弱背离 1 日新变化”的连续文本。

详情抽屉保留完整 Lifecycle 解释：当前状态、规则原因、持续天数、是否今日切换，以及“上一状态 → 当前状态”。明确标注 Lifecycle 是研究观察标签，不构成交易建议。

## 排行榜与抽屉视觉

排行榜桌面布局扩大最右侧“变化”列，箭头和绝对排名变化值均不可被裁切；移动端保留紧凑布局但显示数值。

详情抽屉内“板块行情”上方的说明改为统一的信息卡：带边框、深色表面、标题/口径/截至日期三层文字，并与 K 线卡、评分拆解卡保持同一间距、圆角、边框语言。

## 验收与测试

- 日期月历默认收起；点击打开后不改变筛选区布局高度；Escape、外部点击和二次点击均关闭。
- 市场总览只渲染市场级卡片，不再提供 Lifecycle 筛选按钮。
- 观察重点标签正确更新阶段/Lifecycle/今日变化筛选，且选中状态可访问。
- 排行榜显示 Lifecycle 短标签和完整排名变化数值。
- 抽屉显示统一行情信息卡及完整 Lifecycle 状态迁移说明。
- 回放、层级切换、无 Lifecycle 历史快照和待生成交易日回退行为维持现有契约。

## 非目标

- 本轮不新增任何具体市场指标数据源或计算。
- 不改变 Lifecycle 判定规则、P1/P2 评分逻辑或自动交易行为。
