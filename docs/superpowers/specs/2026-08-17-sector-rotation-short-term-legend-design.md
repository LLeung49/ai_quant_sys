# 行业轮动短期异动图例澄清设计

## 目标

消除象限气泡图中“方向颜色”与“强度颜色”被误读为两套同时生效的颜色编码。

## 决策

保留五种方向颜色；将强度图例改为真实的形状编码说明，而不再展示橙、黄、绿三种独立色块。

## 展示规则

- “短期异动方向”：维持涨红、跌绿、量能、反弹、破位五个彩色圆点。
- “强度”：用同一中性色展示强 / 中 / 轻三档的实、半透明、淡化状态；标签明确为“形状实 / 半透明 / 淡”。
- 提示文案明确：强度同时由透明度、形状大小和发光表达；脉冲上涨、脉冲下跌的三角形额外以尖锐度表达强度，越尖越强。

## 范围与兼容性

只修改 `SectorRotationPage` 中的图例 DOM 文案及样式钩子，不改变短期标签、强度计算、气泡图渲染或后端接口。新增前端测试，防止旧的三档颜色词重新出现。

## 验收

- 图例不再把橙、黄、绿解释为主图形的强度颜色。
- 使用者可从图例直接得知：颜色看方向，透明度 / 大小 / 发光看强度，脉冲三角另看尖锐度。
- 既有方向图例及象限图功能保持不变。
