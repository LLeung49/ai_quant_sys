# QMT 脏行情行的 AkShare 精确降级设计

## 目标

在 `8-原始行情与复权数据采集.py` 中，当 QMT 返回的某个日线行包含无效 OHLCV 值时，仅用 AkShare 补齐该行。正常的 QMT 行不得被替换。

## 范围与数据流

处理单位为 `(stock_code, dividend_type, trade_date)`。采集器先读取 QMT 三种价格投影；核心字段 `open`、`high`、`low`、`close`、`volume`、`amount` 中非有限值或无法转换为数字的行进入回退候选集合。候选日期按连续区间请求 AkShare，避免为每一行分别发起网络请求。

模式映射沿用临时修复脚本：`none` 使用不复权数据，`front` 使用 `qfq`，`back` 使用 `hfq`。

## AkShare 回退

每个连续区间优先调用东方财富的 `ak.stock_zh_a_hist`；调用失败、响应为空或未能提供需要的有效行时，再调用新浪的 `ak.stock_zh_a_daily`。代码转换沿用旧脚本：东方财富使用六位代码，新浪使用 `sh`/`sz` 前缀。

只有交易日精确命中候选日期且核心 OHLCV 全部有效的 AkShare 行可作为替代值。回退行与正常 QMT 行合并，仍通过现有批量 UPSERT 写入各自的原始、前复权、后复权表。

## 失败与可观测性

AkShare 两个来源均失败、目标日期缺失或返回的值仍无效时，不写入该候选行；该证券在对应批次记为失败，并输出代码、模式、日期及失败原因。正常 QMT 行仍然写入，其他证券不受影响。

## 测试

测试覆盖 QMT 脏行被精确替换、正常 QMT 行保持不变、东方财富失败后使用新浪，以及回退行缺失导致该代码失败且不写入脏值。
