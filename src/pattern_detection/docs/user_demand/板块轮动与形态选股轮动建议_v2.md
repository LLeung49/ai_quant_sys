# 四、ETF 这条线，我建议变成“板块 Gate + ETF Timing”

你的 ETF Core 应该是整个系统最稳定的一条链路：

**Market Regime  
→ Sector Opportunity  
→ Sector ETF Mapping  
→ ETF Timing  
→ ETF Risk/Liquidity  
→ Core Candidate**

也就是说 ETF 不应该从 MACD Pool 直接购买。

先通过 Sector Gate：

例如只有

`trending / emerging`

并且排名、参与度、Phase Confidence 合格的板块才允许进入 ETF Candidate。

然后 ETF 自己再满足：

MACD 近期金叉、零轴状态、ER、ADX、MA60、量能。

最后还要增加 ETF 本身的：

成交额、跟踪误差、规模、流动性、溢折价等“交易适配指标”。

这样系统最终输出的不是：

> 创新药 ETF MACD 金叉

而是：

> **医药板块：中期 trending + 短期 pulse_up  
> → 行业环境支持  
> → 创新药 ETF：T-1 金叉 + ER 上升 + ADX 强化  
> → Core ETF Candidate**

这才是一个真正能够支撑决策的完整逻辑。

你的 MACD 文档后续其实已经规划了“板块 Lifecycle + MACD 并列研究”和 5/10/20 日 OOS，我认为这两个应该直接升到高优先级。

# 五、个股部分，我会修改之前的设计：不要做一个“万能个股分”

这里是我对之前《板块轮动与形态选股轮动建议》最大的修正。

原来的设计提出三个池：

修复候选、趋势龙头、风险观察。这个框架仍然很好。

但我现在更建议你把个股 Alpha **正式拆成两套完全不同的策略**。

### A. 趋势龙头 Alpha

服务于：

**Sector = accel_up / trending**

目标不是找低估，而是：

> 找出“板块上涨 Beta 之外，还在产生个股 Alpha”的股票。

这时候最重要的指标不是股票绝对涨幅，而是：

# [

\text{Stock Alpha}_{5d}

## R_{\text{stock},5d}

R_{\text{sector},5d}  
]

同样计算 10D / 20D。

然后研究：

行业内 RS Rank、RS Rank 持续性、股票相对板块加速度、成交额行业占比、ER/ADX、MA20/MA60、20/60 日突破、缩量回踩、放量再突破等。

**你真正应该预测的是：**

> 在已经看好的行业里，谁能跑赢行业 ETF？

而不是：

> 谁未来会上涨？

这两个研究问题差别非常大。

而且更符合你“ETF 获取 Beta，个股赌 Alpha”的资金结构。

---

### B. Repair / Value Dislocation Alpha

这套只服务于：

**repair / reversal_confirmed / emerging**

你现在已有的 MACD 底背离、锤子线、吞没、早晨之星等，正好适合这里。你之前的文档也已经指出，目前形态雷达本质上偏“底部反转雷达”，不适合作为 accel_up 行业的主要选股工具。

但这里还差一个非常重要的东西：

**估值 / 基本面。**

因为仅靠 K 线，最多能说：

> “技术性超跌修复候选”

不能说：

> “被低估”。

如果你真的想找“被低估 + 正在开始修复”的股票，我建议以后建立：

**Valuation Dislocation Score**

而不是简单 Low PE。

例如比较：

当前 PE/PB/EV-EBITDA 相对自身历史分位、相对同行分位，同时设置 ROE、现金流、利润趋势等 Quality Floor。

形成：

> **估值错位 + 基本面没有明显恶化 + 行业开始修复 + 股价出现确认信号**

这种股票比“PE 最低的股票”有价值得多。

# 六、我会降低之前“连板”在龙头评分里的权重

你之前的设计里：

> 龙头分数 = 35% 相对收益 + 25% 流动性 + **20% 连板/涨停强度** + …

如果你的目标是：

> ETF 做主要仓位 + 小部分个股追求超额收益，同时尽量避免高概率被套，

**热点妖股识别器。**

我会把股票分成：

**趋势龙头** 和 **情绪龙头** 两类。

趋势龙头主要靠相对行业强度、持续性、流动性和趋势质量。

涨停、连板只作为 5%～10% 的增强特征。

而“2 连板、3 连板、涨停集群”单独进入：

**Hot Leader Pool**

不要和低波动趋势股混在一起。

**Capital Flow Layer**
