# Lifecycle 与轮动象限结合的研究参考

## 一、两个标签体系分别回答什么

- **轮动象限阶段**回答板块所处的相对强弱和动量位置：加速走强、强势降温、弱势修复观察、修复确认、加速走弱。
- **Lifecycle**回答该位置的成熟度和风险状态：是刚开始改善、趋势延续，还是已出现拥挤、背离或转弱。

两者应组合使用，而不是强行一一对应。页面输出的是研究观察，不构成交易建议。

## 二、当前前端页面的阅读顺序

| 前端位置 | 主要信息 | 用途 |
| --- | --- | --- |
| 象限图与排行榜的“阶段” | 五类轮动阶段 | 判断板块的强弱位置与动量方向 |
| 象限图标题旁“观察重点” | 全部、趋势、修复/初启、风险提示、今日 Lifecycle 变化 | 快速缩小研究范围 |
| 右侧排行榜 | Lifecycle 短标签、持续天数、今日切换、排名变化 | 判断状态是否新出现，及相对强弱是否支持 |
| 行业详情抽屉的 Sector Insight | `阶段 · Lifecycle` 组合结论、原因、前态变化 | 将双层标签翻译为研究重点 |

建议顺序：先看阶段，再用 Lifecycle 判断成熟度/风险，最后用排名变化与市场环境交叉确认。

## 三、阶段与 Lifecycle 的组合参考

| 象限阶段 | Lifecycle | 研究参考 |
| --- | --- | --- |
| 加速走强 | 初步启动、趋势运行 | 优先进入“趋势”观察，重点跟踪强度、排名是否继续改善、市场环境是否支持。 |
| 加速走强 | 强势拥挤、强弱背离、加速转弱 | 位置仍强但风险提高，切换到“风险提示”观察；不宜只因排名高而追逐。 |
| 强势降温 | 趋势运行 | 可能仍在趋势内，但动量已放缓；重点看参与度、排名变化，以及是否转为背离。 |
| 强势降温 | 强势拥挤、强弱背离、加速转弱 | 风险组合更明确；避免追逐强势，重点复核风险扩散信号。 |
| 弱势修复观察 | 修复观察、方向未明 | 仅进入观察池；出现修复迹象不等于修复已经确认。 |
| 修复确认 | 初步启动 | 典型的改善确认组合；进入重点跟踪，仍等待排名与市场环境共同确认。 |
| 修复确认 | 趋势运行 | 修复后进一步形成趋势，可继续研究其持续性。 |
| 加速走弱 | 加速转弱 | 两层信号一致偏弱，优先回避，并观察后续是否先回到修复观察。 |

## 四、页面中的快速操作

1. 在象限图识别行业当前所属阶段。
2. 使用“观察重点”快速筛选：
   - **趋势**：寻找趋势延续线索。
   - **修复/初启**：寻找改善与早期启动线索。
   - **风险提示**：检查拥挤、背离、转弱风险。
   - **今日 Lifecycle 变化**：检查当天刚发生状态切换的行业。
3. 查看排行榜：确认 Lifecycle 的持续天数、是否“今日切换”、以及排名变化数值。
4. 打开行业详情抽屉：优先阅读 Sector Insight 的组合结论及状态原因。

## 五、组合结论示例

- `修复确认 · 初步启动`：可进入重点跟踪，等待排名与市场环境共同确认。
- `强势降温 · 强弱背离`：强势正在减弱，避免追逐并继续评估风险。
- `加速走弱 · 加速转弱`：风险扩散迹象更明确，优先回避观察。

这些文字用于统一研究语言；最终判断仍应结合市场环境、排名变化、数据覆盖率及个人风险承受能力。
