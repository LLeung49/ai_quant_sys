# 板块轮动使用指南

> 适用对象：`sector_rotation2` 当前已完成版本（默认模型 `v1`）。
>
> 定位：这是一个按交易日生成的板块相对强弱、趋势变化、内部参与度和风险状态研究工具；输出用于晨会、研究筛选和复盘，不构成交易指令或收益承诺。

## 1. 已完成能力与使用边界

当前系统已形成以下闭环：

1. 从申万一级/二级行业日行情、个股复权日线和当前行业成分映射读取数据。
2. 校验价格、成交额、日期完整性和行业 K 线覆盖率；覆盖率低于 `80%` 的行业不参与当日排名。
3. 构造市场基准、计算价格/相对强度/量能/广度特征，并按当日行业横截面标准化。
4. 输出连续评分、市场状态、轮动阶段、排名变化和 Lifecycle 标签；结果以版本化快照落库，可重复查询。
5. 生成日明细 CSV、TopN 文本摘要、数据质量 CSV；提供单日象限、历史轨迹、回放、排行榜和详情展示。
6. 生成前瞻收益标签，支持 IC、分组收益、市场状态分桶、滚动样本外、成本敏感性及 Lifecycle 条件收益研究。

系统不做自动下单，不以 Lifecycle 直接管理真实仓位，不将阶段或排名解释为确定性涨跌预测。

## 2. 每日结果应如何阅读

建议按以下顺序使用：

1. **先看数据资格与市场状态**：`score_eligible=false`、覆盖率不足或字段缺失的行业不进入排名；市场状态决定整体风险暴露口径。
2. **再看排名和主评分**：`composite_rank=1` 为同日、同层级可评分行业中主评分最高者。排名是相对排序，不是预期收益率。
3. **看象限阶段**：速度和加速度描述趋势方向与变化，阶段已经过历史确认，不能只按当天象限位置重算。
4. **用 Lifecycle 辅助判断成熟度和风险**：它将阶段、参与度、排名变化和 Top10 持续时间组合为研究状态，不改变评分或排名。
5. **结合证据复核**：查看 `rank_change_1d/5d`、`phase_age`、`phase_confidence`、`participation_score`、`volume_score`、`coverage_ratio` 与市场状态。

## 3. 数据、基准与质量规则

### 3.1 数据来源

| 数据 | 用途 |
| --- | --- |
| `trade_sector_daily` | 行业收盘指数、成交额、涨跌家数、涨跌停家数、应有/有效 K 线数 |
| `trade_stock_daily_qfq` | 个股收盘价和成交额，用于个股 RVOL 与广度 |
| `trade_stock_status` | 当前申万一级/二级行业成分映射 |
| `sector_rotation_*` 派生表 | 每日快照、运行审计、未来收益标签和回测指标 |

上游行情表仅读取。行业快照按模型版本和配置哈希保存，因此同一版本可以追溯和复现。

### 3.2 市场基准

同一行业层级内，通过校验的行业构成市场基准：

- 价格：每个行业先按自身首日收盘归一化，再等权平均；
- 成交额：有效行业成交额求和；
- 市场上涨广度：行业 `breadth_up` 的中位数，避免大行业单独主导；
- 历史计算只使用目标交易日及此前数据，不用未来数据补齐窗口。

### 3.3 排名资格

- 行业至少有 `90` 个有效交易日才进入每日特征面板。
- `coverage_ratio = kline_stock_count / stock_count`；低于 `0.80` 时保留原始信息，但不参与当日截面评分和排名。
- 价格非正、成交额为负、重复日期、日期未升序或必要字段缺失的行业跳过。
- 每个原始指标的横截面有效样本少于 `20`，或所有值相同，则该指标评分为缺失；缺失不以 `0` 代替。

## 4. 原始量化指标/因子

所有时间窗口均为交易日。

| 类别 | 字段与公式 | 含义 |
| --- | --- | --- |
| 收益与相对强度 | `ret_5/20 = P_t / P_(t-n) - 1`；`rs_5/20/60 = 行业 n 日收益 - 市场基准 n 日收益` | 行业相对市场的短、中、长期表现 |
| 均线位置 | `distance_ma20/60 = P_t / MA20/60 - 1` | 当前价格相对趋势均线的位置 |
| 趋势速度 | `ma20_slope`：MA20 在 10 日窗口的最小二乘斜率 | 趋势运行方向和速度的原始证据 |
| 趋势加速度 | `rs20_accel = rs_20,t - rs_20,t-5`；`ma20_accel = ma20_slope,t - ma20_slope,t-5` | 相对强度和均线斜率是否在改善或恶化 |
| MACD | `macd_hist_delta`：12/26/9 MACD 柱（HIST×2）的单日变化 | 动量变化；评分使用柱变化，不直接使用柱绝对值 |
| 行业量能 | `rvol_5_20`、`rvol_5_60`：近 5 日平均成交额/近 20 或 60 日平均成交额 | 近期量能相对历史是否活跃 |
| 资金份额 | `amount_share = 行业成交额/有效行业总成交额`；`share_impulse = 当日份额/前 20 日份额均值` | 行业在市场成交额中的份额及其提升程度 |
| 上涨广度 | `breadth_up = rise_count/(rise+fall+flat)` | 行业内当日上涨股票占比 |
| 个股参与度 | `breadth_above_ma20`、`breadth_new_high_20`、`breadth_rvol`、`median_stock_rvol` | 行业内站上 MA20、20 日新高、放量股票占比和典型个股量能 |

## 5. 连续评分与排名

### 5.1 标准化方法

每个指标在“同日、同层级、具备资格”的行业截面中计算有符号百分位得分，范围为 `[-1, 1]`。因此：

- `0` 表示截面中性，不表示收益率为零；
- 正负表示相对其他行业更强或更弱；
- 不同日期的绝对值不应脱离当日截面直接比较。

每个评分组至少需要两项可用原始证据；组内对可用项等权平均。

### 5.2 五类评分

| 评分 | 组成 | 是否进入主评分 |
| --- | --- | --- |
| `trend_level_score` | `rs_20`、`rs_60`、`distance_ma20`、`distance_ma60` | 是，45% |
| `velocity_score` | `rs_5`、`rs_20`、`ma20_slope` | 是，25% |
| `acceleration_score` | `rs20_accel`、`ma20_accel`、`macd_hist_delta` | 是，15% |
| `participation_score` | `breadth_up`、`breadth_above_ma20`、`breadth_new_high_20`、`breadth_rvol` | 是，15% |
| `volume_score` | `log(rvol_5_20)`、`log(share_impulse)` | 否，仅作为量能诊断/气泡大小 |

`strength_score` 是 `trend_level_score` 的兼容别名。

### 5.3 主评分、综合评分与排名

```text
base_score = 可用主评分按 45%/25%/15%/15% 重新归一化后的加权均值
composite_score = base_score × regime_multiplier
```

- 可用主评分权重之和低于 `0.60` 时，`score_eligible=false`，不产生 `composite_rank`。
- `composite_rank` 按 `base_score` 从高到低排名，`1` 为最高；并列采用最小名次。
- 市场状态乘数对所有行业相同，只缩放整体风险暴露，不改变同日行业排序。
- `phase` 与 Lifecycle 均不加分、不改 `base_score`、`composite_score` 或排名。

## 6. 市场状态（Market Regime）

市场状态按固定优先级判断，结果及风险乘数如下。

| 优先级 | 状态 | 判断条件 | `regime_multiplier` |
| ---: | --- | --- | ---: |
| 1 | `risk_off` | 市场收盘低于 MA60、市场上涨广度低于 0.45、且跌停数大于涨停数 | 0.70 |
| 2 | `high_volatility` | 20 日绝对收益率不低于 8%，或 20 日收益波动率处于最近 252 个有效观测的 80% 分位以上 | 0.85 |
| 3 | `risk_on` | 市场收盘高于 MA20 且 MA20 高于 MA60、上涨广度不低于 0.55、且成交额高于 MA20 | 1.00 |
| 4 | `range` | 其他情况或市场窗口不足 | 0.90 |

用途是给晨会的整体环境和风险暴露提供统一背景。它不表示未来市场方向，也不用于重排行业。

## 7. 轮动象限与阶段（Phase）

### 7.1 象限坐标和视觉编码

| 图形属性 | 字段 | 阅读方式 |
| --- | --- | --- |
| 横轴 | `velocity_score` | 相对趋势速度；右侧偏强、左侧偏弱 |
| 纵轴 | `acceleration_score` | 趋势变化；上方改善、下方恶化 |
| 气泡面积 | `volume_score` | 相对量能/资金活跃度 |
| 描边 | `participation_score` | 行业内部参与度 |
| 颜色 | `phase_confirmed` | 已确认阶段 |
| 透明度 | `phase_confidence` | 阶段证据强度 |

象限是阅读辅助。最终阶段必须读取历史确认结果，不能只依据当天坐标归类。

### 7.2 原始阶段与确认规则

对速度和加速度均使用迟滞阈值：首次进入或反向切换使用 `±0.25`；已处于同一方向时使用 `±0.10`。

| 速度 | 加速度 | `phase_raw` | 页面文案 |
| --- | --- | --- | --- |
| 正 | 正 | `accel_up` | 加速走强 |
| 正 | 负 | `decel_up` | 强势降温 |
| 负 | 正 | `bottoming_candidate` | 弱势修复观察 |
| 负 | 负 | `accel_down` | 加速走弱 |
| 其他/缺失 | 其他/缺失 | `neutral` | 方向未明 |

`phase_confirmed` 规则：候选非中性阶段须在“当前日加前两日”中至少出现两次；否则延续上一确认阶段，首次无历史时为 `neutral`。`phase_age` 为当前确认阶段已连续的交易日数，`phase_changed` 表示相对前一日是否切换。

`bottoming_candidate` 仅是观察标签，不产生加分。若至少命中两项反转证据，确认成 `reversal_confirmed`：`rs_5>0`、价格在 MA20 上方、`breadth_up>0.50`、`share_impulse>1`、速度由非正穿越至正、或排名连续两日改善。

### 7.3 阶段置信度

```text
phase_confidence = min(1,
  [0.35×|速度| + 0.35×|加速度| + 0.20×max(参与度, 0) + 0.10×min(phase_age/3, 1)] / 可用权重和)
```

速度或加速度缺失时置信度缺失；参与度缺失时其权重从分母移除。置信度描述当前模型证据强弱，不是成功概率。

## 8. Lifecycle：状态、动作标签和计算逻辑

Lifecycle V0 在评分与阶段之后计算，用于研究和人工决策辅助，优先级低于市场风险判断和 Sector Score。它不改动评分或排名。

| 优先级 | 条件 | `lifecycle_state` | `lifecycle_action` | 研究仓位乘数 | 原因字段 |
| ---: | --- | --- | --- | ---: | --- |
| 1 | 无评分资格 | `neutral` | `observe` | 0.00 | `score_ineligible` |
| 2 | 已确认加速走弱 | `exit` | `exit_or_avoid` | 0.00 | `phase_accel_down` |
| 3 | 强势降温且参与度或 1 日排名变化为负 | `divergence` | `reduce` | 0.25 | `decel_up_with_fading_breadth_or_rank` |
| 4 | 强势降温且最近 20 日累计 Top10 天数不少于 15 | `crowded` | `hold_or_trim` | 0.50 | `decel_up_with_extended_top10_duration` |
| 5 | 已确认加速走强 | `trending` | `hold_or_add` | 1.00 | `phase_accel_up` |
| 6 | 已确认修复 | `emerging` | `hold_or_probe` | 0.50 | `reversal_confirmed` |
| 7 | 原始阶段为修复候选 | `repair` | `watch_or_probe` | 0.25 | `repair_phase` |
| 8 | 强势降温且未触发上述风险条件 | `emerging` | `hold_or_probe` | 0.50 | `decel_up_without_warning` |
| 9 | 其他情况 | `neutral` | `observe` | 0.00 | `no_lifecycle_signal` |

`lifecycle_changed` 标识当天是否改变状态，`lifecycle_age` 是该状态连续天数。研究仓位乘数是模型输出的人工研究参考，不是账户仓位指令。

### 8.1 Phase 与 Lifecycle 组合使用

| 阶段 + Lifecycle | 建议研究重点 |
| --- | --- |
| 加速走强 + `trending` | 跟踪排名、参与度及市场环境是否持续支持 |
| 强势降温 + `divergence`/`crowded` | 复核广度、排名和拥挤风险，不因排名高单独追逐 |
| 修复确认 + `emerging` | 放入重点跟踪，等待排名和市场环境共同确认 |
| 弱势修复观察 + `repair` | 观察池，不视为修复已确认 |
| 加速走弱 + `exit` | 优先回避并等待后续修复证据 |

## 9. 输出、页面和使用场景

### 9.1 日常输出

成功快照落库后，系统生成：

- `sector_rotation2_daily_<date>.csv`：全量特征、评分、阶段、Lifecycle 和市场状态；
- `sector_rotation2_topN_<date>.txt`：可评分行业 TopN 的排名、综合分、阶段、Lifecycle、动作标签和研究乘数；
- `sector_rotation2_data_quality_<date>.csv`：覆盖率、评分资格和缺失字段数量。

### 9.2 Web 工作台

当前页面支持一级/二级行业切换、日期选择、市场摘要、象限气泡、关注筛选、排行榜、行业详情、行业 5/20/60 日轨迹和全市场逐日回放。页面只读取成功运行的快照；缺失值显示为“数据不足”，不伪造为零或原点。

### 9.3 适用场景

- **晨会扫描**：先看市场状态、数据覆盖告警、Top 行业和当日状态变化。
- **主题研究筛选**：用主评分和排名找到相对强势行业，再以参与度、量能和阶段确认检验是否存在内部共振。
- **趋势跟踪**：关注 `accel_up`/`trending` 的 `phase_age`、排名变化和广度。
- **转弱与拥挤复盘**：关注 `decel_up`、`divergence`、`crowded`、`accel_down`，核查它们出现前后的量能、广度和排名变化。
- **历史研究**：使用成熟的 1/2/3/5/10/20/40 日前瞻收益标签，检查因子 IC、五分组、市场状态分桶、滚动样本外和交易成本敏感性。

## 10. 回测与研究口径

- T 日快照只使用 T 日及此前可得数据；前瞻收益从 T 日收盘到 T+N 日收盘计算。
- `phase_confirmed`、排名变化、Top10 累计天数和 Lifecycle 都按历史快照顺序构建，不读取未来状态。
- 回测可评估 `trend_level_score`、`velocity_score`、`acceleration_score`、`volume_score`、`participation_score`、`base_score` 和 `composite_score` 的 IC、Rank IC、五分组收益等指标。
- 当前研究入口还输出市场状态分桶、滚动样本外窗口、Top 五分组的不同调仓频率/成本敏感性，以及 Lifecycle 状态和 Score 分桶条件收益。
- 当前 `v1` 不依据单段历史结果自动调权。新权重版本的准入标准是：至少两个独立样本外窗口的 5 日 `composite_score` Rank IC 均值为正、Top 组相对 Bottom 组平均超额收益为正、且换手率不高于当前版本的 120%。

## 11. 核心限制与风险

| 限制 | 事实与影响 |
| --- | --- |
| 指标滞后 | MA20/MA60、RS20/RS60、滚动量能和广度都依赖历史窗口；阶段还使用迟滞与最近 3 日 2 次确认。因此信号以稳定性换取及时性，转折初期可能晚于价格变化。 |
| 横截面相对性 | 所有分数是同日行业相对位置；全市场普涨时的高分不等于绝对收益高，全市场下跌时的低分也不等于唯一的风险来源。 |
| 行业映射历史偏差 | 当前成分股数据使用 `current_mapping`，没有严格的历史成分变更映射；历史回测可能存在成分幸存者/回填偏差，报告必须披露该口径。 |
| 数据覆盖与缺失 | 覆盖率不足、个股日线缺失、样本不足或截面样本太少时，部分因子/评分为空，行业不应被当作中性或参与排名。 |
| 基准构造 | 市场基准是有效行业的归一化等权价格与成交额求和，不等同于宽基指数或市值加权行业指数。 |
| 量能解释 | RVOL、成交额份额和量能得分描述相对活跃度，无法单独区分主动买入、被动成交、事件冲击或换手。 |
| 阶段与 Lifecycle | 两者是规则型解释/研究标签，不是价格预测模型；`phase_confidence` 不是胜率，研究仓位乘数也不是实际仓位建议。 |
| 参数稳定性 | 评分权重、阈值和市场状态参数已固定并版本化，但其跨市场阶段稳定性仍须通过滚动样本外验证。 |
| 交易可实现性 | 当前结果不覆盖个股/ETF 流动性、冲击成本、容量、停牌、涨跌停约束、税费或组合层面的风险控制。 |

## 12. 后续迭代方向

后续工作应在独立模型版本和样本外验证后推进：

1. **严格历史行业成分**：引入成分变更历史表，将 `current_mapping` 切换为 `historical_mapping`，降低历史研究偏差。
2. **评分稳健性**：评估百分位标准化是否需要替换/补充为 robust-z；在滚动训练与样本外中检验权重、阶段阈值和市场状态参数。
3. **集中度因子**：在获得按历史日期可得的自由流通市值或可靠市值权重后，再实现少数龙头主导/领导力集中度；不得用当前市值回填历史。
4. **因子研究扩展**：按市场状态、行业层级、样本期和持有期持续验证 Alpha 衰减、换手、成本和 Lifecycle 的增量解释力。
5. **可视化与工作流**：在现有象限、轨迹和回放基础上扩展自选板块、变化提醒、持仓联动、主题/个股下钻；需另行设计权限、数据口径和合规提示。
6. **组合与风控对接**：仅在独立规格中明确风险预算、容量、成本、流动性和执行规则后，才评估与组合层风险引擎的接口；不直接由当前评分驱动下单。
