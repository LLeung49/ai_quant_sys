# 板块轮动统一工作台设计补充

## 1. 目标

将“行业轮动象限”和“全市场轮动回放”合并为同一张象限图。单日观察与动态回放共享视觉编码、筛选、选择、摘要和排行榜，任何时刻页面只存在一个有效的展示日期，避免口径错位。

## 2. 工作台模式

- `snapshot`：显示顶部日期选择器对应的单日快照。
- `replay`：使用一次性预加载的历史点在本地逐日切帧；播放过程不再次请求 API。
- 回放时，市场摘要、象限图、排行榜和行业详情全部使用当前回放帧。
- 退出回放时恢复用户进入回放前选择的单日日期。
- URL 保存 `date`、`level`、`mode`、`phase`、`q`、`sector` 和轨迹窗口，刷新后可恢复研究现场。

## 3. 智能标注

标签密度支持 `compact`、`focus`、`all`。默认 `focus`，桌面端最多优先展示约 30 个行业，移动端降低数量。优先级按以下证据累计，任何被选中或搜索命中的行业强制显示：

1. 当前选中；
2. 综合排名靠前；
3. `phase_changed=1`，阶段刚切换；
4. `abs(rank_change_1d)` 或 `abs(rank_change_5d)` 较大；
5. `abs(acceleration_score)` 位于极值区；
6. `phase_confirmed=accel_down`；
7. `phase_confirmed=reversal_confirmed`。

标签使用 ECharts 避让；重叠时优先保留更高优先级。Tooltip 顶部显示“关注原因”，多个原因同时展示，例如“阶段刚切换 · 1日排名上升14位 · 加速度极值”。

## 4. 双层轨迹

### 4.1 主图尾迹

回放模式选中一个行业后，在主象限图显示截至当前帧最近 10 个成功交易日的尾迹。旧节点逐渐变暗，当前节点高亮；不跨越缺失点插值。尾迹只用于追踪当前行业，不同时绘制全市场历史线。

### 4.2 轨迹分析

独立轨迹分析组件用于横向比较最多五个行业，支持 5/20/60 个交易日。用户可从排行榜或详情将行业加入对比；组件显示图例、最新节点、阶段切换和历史缺口。它与主图的职责不同：主图回答“全市场当前在哪里”，轨迹分析回答“关注行业如何走到这里”。

五行业上限同时作用于页面选择状态、前端 API 客户端、FastAPI 参数校验和只读仓储，避免各层边界不一致。前后端分别使用命名常量表达上限，不在业务代码中散落数字 `5`。前端为五条轨迹提供固定且高对比度的颜色，同一选择顺序在不同窗口下保持颜色稳定。用户已选择五个行业后继续点击其他行业时，不替换已有选择，并明确提示“最多 5 个”；移除任一行业后可以继续加入。

历史接口仍采用参数化 `IN` 查询，一次只允许 1 至 5 个行业。第六个行业由前端预检和服务端校验共同拒绝，错误不触发无界查询。该调整只改变查询上限，不新增字段或持久化表。

## 5. 验收

- 最新回放帧与同日期单日观察的气泡、摘要和排名一致。
- 页面中只有一个全市场象限图。
- 默认关注标注明显多于原实现，同时不因标签重叠遮蔽主要气泡。
- 每个重点标注行业的 Tooltip 都能解释被关注原因。
- 选中行业后回放尾迹随时间轴前后移动。
- 回放不产生逐帧网络请求。
- 轨迹对比可以同时展示五个行业，第六个行业不会替换已有选择。
- 五条轨迹颜色可区分，并在 5/20/60 日窗口切换时保持稳定。
- 前端和后端均拒绝一次查询六个行业，历史缺口不插值。
